The archive in this repository contains the desktop application itself plus the runtime components required for the first launch.

## 🚀 Key Features

| Feature | Description |
| --- | --- |
| 🎚️ Metering | Level and dynamics meters show what the chain does to the signal. |
| 🔍 Chain Processing | Modules are arranged in series and reordered in the chain. |
| 📊 Spectrum Tools | Frequency-dependent work is done with visual feedback. |

| Display | 1280 x 800 or higher, 1920 x 1080 recommended |
| Storage | 2 GB free disk space for the application and its presets |

## Additional Information for Windows Users

Hardware headroom matters more than the minimum list suggests: previews and batch jobs scale with RAM and VRAM, not with CPU clocks alone.

A slow first launch is usually the one-time runtime registration; later starts skip that step.
